# App Connector v1 spec

Date: 2026-10-30. Terms are defined in `GLOSSARY.md`.

## Problem

My Apps live at different addresses. I want one home-screen app that lists them all and opens
any of them in one tap, for me and Aubyn.

## Decisions

- **Users**: me and Aubyn, same Tiles for both. No sign-in; it's a public page of links and each
  App keeps its own auth.
- **Hosting**: `apps.ashershores.com`, same personal AWS account and Route 53 zone as HoneyDo,
  separate stacks, us-west-1 (certificate in us-east-1). Pushes to `prod` deploy through GitHub
  Actions OIDC, like Games Catalog. A $1/month tag-based budget (`app=app-connector`).
- **Stack**: mirrors Games Catalog, minus the backend: TS npm workspaces `web` (Vite PWA) and
  `infra` (CDK: S3 + CloudFront + ACM + Route 53). No Lambda, DynamoDB or Cognito. Add
  `shared`/`api` only if live badges or sign-in come later.
- **Installable**: its own PWA, home-screen label "Apps", works offline (the Tile list and icons
  are cached).
- **Tiles**: a static config in the repo, in this order (HoneyDo top left):
  1. HoneyDo, https://honeydo.ashershores.com
  2. NutriSageAI, https://ashershores5.github.io/NutriSageAI/docs/
  3. Games Catalog, https://games.ashershores.com
  4. Exam Prep Lab, https://exampreplab.com
- **Icons**: a copy of each App's icon is committed to this repo, not linked live.
- **Layout**: iOS-style icon grid with names below. Light/dark follows the system.
- **Opening an App**: tapping a Tile opens the App. On iPhone that opens a Safari sheet (iOS
  can't open an installed PWA from a link). On desktop it opens a new tab so App Connector stays
  open as a start page.
- **Install hint**: each Tile has a small (i) button opening a sheet with "Share > Add to Home
  Screen" steps and the App's address. App Connector can't tell whether an App is already
  installed, so the hint is always available.
- **Embedding**: Apps are never framed or embedded.

## Out of scope for v1

Live badges (e.g. Chores due); sign-in; per-person Tile sets; editing Tiles in the app;
placeholder Tiles for unbuilt Apps (an App gets a Tile when it ships); App health/status.

## User stories

1. I open "Apps" from my home screen and see four icons, HoneyDo top left.
2. I tap HoneyDo and it opens.
3. On my laptop, I click Games Catalog and it opens in a new tab; App Connector stays open.
4. Aubyn taps (i) on NutriSageAI and follows the steps to add it to her home screen.
5. With no signal, App Connector still opens and shows all four icons.
6. I add a fifth App by editing the config and an icon file, then pushing to `prod`.
